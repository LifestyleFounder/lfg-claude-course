Outcome

What You're Installing

The Call Pipeline is a three-skill system that runs inside Claude Code and turns every Zoom recording into structured, searchable, actionable data — without you ever touching a transcript, and without paying a single extra penny in API costs.

The Three Commands

/process-calls

Pulls every Zoom recording from the last 24 hours. Classifies each as coaching / sales / workshop / group. Extracts a 3-sentence summary, action items (with owners and deadlines), and content idea seeds. Writes everything to your Supabase database and creates a Notion page per call. Idempotent — safe to rerun.

/mine-calls

Reads processed transcripts from Supabase. Generates 3–5 pre-written content hooks per call — in your voice — each with a format suggestion (Reel, carousel, email, workshop angle), a one-line angle, and the source quote with timestamp. Drops them into Notion as proper formatted blocks.

/call-digest

End-of-day rollup. Queries every call from today. Builds a clean digest grouping action items and content ideas by call. Publishes to a "Daily Digests" Notion database and emails the digest to your inbox so you close the day knowing what came out of every conversation.

Setup

The 4-Step Install

Run /lfg:setup-call-pipeline in Claude Code and follow the prompts — the command walks you through these steps interactively. This guide is the visual reference.

01

Provision Supabase

Sign up at supabase.com. Create a new project (free tier). Wait ~2 minutes for it to provision.

Open the SQL Editor → New query. Copy the schema file:

cat ~/.lfg/setup/supabase-schema.sql | pbcopy

Paste into the SQL editor and click Run. You should see "Success. No rows returned." Verify by checking the Table Editor — three tables should now exist: calls, call_action_items, call_content_ideas.

02

Duplicate the Notion Template

Open the LFG Call Pipeline template:

→ LFG Call Pipeline · Database Template

In the top-right, click Duplicate → choose your workspace as the destination.

You now own a copy with two databases pre-built: Calls and Daily Digests. Don't rename properties — the skills look up columns by name, so renames break the integration.

For each database, click ⋯ → Copy link to view. Paste both links back into Claude during the setup prompt. Claude will extract the data source IDs automatically.

03

Connect the MCP Servers

In Claude Code, open Settings → MCP Servers. You need five connected:

  • Supabase — paste the project URL + service role key from your Supabase dashboard (Settings → API)
  • Notion — one-click OAuth
  • Zoom — one-click OAuth (Pro+ required for cloud recordings)
  • Google Calendar — one-click OAuth
  • Gmail — one-click OAuth (used to send the daily digest)
Heads up: If Zoom complains about permissions, the most common cause is that your Zoom plan doesn't include cloud recording. The integration only sees cloud recordings — local recordings stay on your machine and never reach Zoom's API.
04

Write the Config File

The setup command will ask you four questions and write ~/.lfg/call-pipeline.json with your answers:

  • Email — where the daily digest gets sent
  • Name — used in greetings
  • Voice description — one sentence describing how you want hooks written. This is the most important answer.
  • Active 1:1 client names — for auto-classifying their calls as "coaching"

After the config file is written, optionally edit two prompt files to customize the AI's voice:

open ~/.claude/skills/call-capture/references/extraction-prompt.md
open ~/.claude/skills/mine-calls/references/hook-prompt.md

Both files have a "Voice (CUSTOMIZE THIS)" section. The more specific you are about your voice, the better the hooks. Reference creators you sound like, banned words, hook patterns you favor.

First Run

After setup completes, run your first capture:

/process-calls

If you have a recent Zoom cloud recording, Claude will pull it, classify it, extract everything, and write to Supabase + Notion in about 30 seconds — all inside your Claude Code session. Open Notion to see it land.

Then run /mine-calls to generate content hooks from that call. And /call-digest at end of day to email yourself the rollup.

Troubleshooting

Common Issues

"No recordings found" when running /process-calls

Three causes, in order of likelihood:

  1. Recording is local, not cloud — Zoom Pro+ needed; check Settings → Recording → Cloud Recording is on
  2. Recording is still processing — Zoom takes 5–30 min after a call ends to make the recording API-accessible. Run again in 15 min.
  3. Zoom MCP scope — the integration may not have permission to read recordings. Reconnect the MCP server.

"Config not found at ~/.lfg/call-pipeline.json"

You skipped Step 4 or the file got deleted. Re-run /lfg:setup-call-pipeline.

Notion writes silently fail (Supabase row created, no Notion page)

Almost always a property name mismatch. The skills look up Notion columns by name — if you renamed "Action Items" to "Actions" in your duplicated database, the write fails. Restore the original property name. (Refer to the Notion template spec in the repo.)

Hooks don't sound like me

Edit the Voice section of ~/.claude/skills/mine-calls/references/hook-prompt.md. Be specific. Mention creators you sound like. Mention words you'd never use. Run /mine-calls --all to re-mine all calls with the updated prompt (confirm before — deletes old ideas).

"You've reached your usage limit" mid-batch

You hit your Claude Pro or Max usage cap. Two options: process calls in smaller batches (3–5 at a time), or upgrade to a higher tier. Most coaches doing 1–2 calls/day never see this on Pro. Heavy users (10+ calls/day) should be on Max ($100 or $200/mo).

Updating to a new pipeline version

Run /lfg:update. It re-downloads the latest skill code and prompts. Your config file and customized prompt edits are preserved (the installer only seeds files that don't exist locally).
